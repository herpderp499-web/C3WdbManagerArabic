# C3 WDB Manager Arabic

واجهة Windows عربية مبسطة لفك وإعادة بناء قاعدة بيانات الرسومات `c3.wdb` المستخدمة في بعض إصدارات **Conquer Online**.

[تنزيل أحدث نسخة جاهزة للتشغيل](https://github.com/herpderp499-web/C3WdbManagerArabic/releases/latest)

## المميزات

- اختيار ملف `c3.wdb` مباشرة دون تجهيز المسارات يدويًا.
- فك جداول WDB إلى ملفات INI قابلة للقراءة والتعديل.
- عرض أسماء ملفات INI الناتجة وأحجامها وحالتها.
- إعادة بناء `c3.wdb` من ملفات INI.
- قبول مجلد `ini` نفسه أو المجلد الأب عند إعادة البناء.
- إنشاء نسخة احتياطية تلقائيًا قبل إعادة البناء.
- واجهة عربية ورسائل خطأ مفهومة بدل رسائل الأداة الصينية القديمة.

## الاستخدام

### فك WDB

1. افتح تبويب **فك ملف WDB**.
2. اختر ملف `c3.wdb`.
3. اختر مجلد الإخراج.
4. اضغط **فك الملف الآن**.

سيتم إنشاء:

```text
c3-unpacked/
└── ini/
    ├── c3.wdb
    ├── RolePart.ini
    ├── 3DObj.ini
    ├── 3DTexture.ini
    └── ...
```

### إعادة البناء

1. عدّل ملفات INI المطلوبة.
2. افتح تبويب **إعادة بناء WDB**.
3. اختر مجلد `ini` أو المجلد الأب الذي يحتوي عليه.
4. اضغط **إعادة بناء c3.wdb الآن**.

قبل التعديل سيُنشئ البرنامج نسخة احتياطية باسم:

```text
c3.before-pack-YYYYMMDD-HHMMSS.wdb
```

## البناء من السورس

المتطلبات:

- Windows 10/11
- .NET 9 SDK
- معمارية x86 بسبب مكتبات WDB الأصلية ذات 32 بت

```powershell
dotnet restore
dotnet build -c Release
```

الناتج سيكون داخل:

```text
bin/Release/net9.0-windows/win-x86/
```

## ملاحظة عن مكتبات WDB

الواجهة مكتوبة بـ C#، بينما `WdbExtractor.dll` و`WdbGenerater.dll` مكتبتان أصليتان قديمتان من أداة WdbManager لعام 2013. تم تضمينهما للتوافق وتشغيل وظائف الفك وإعادة البناء؛ حقوقهما تعود إلى أصحابها الأصليين.

المشروع مخصص لأغراض التوافق، صيانة الملفات، والبحث التقني. لا يحتوي المستودع على ملفات لعبة أو أصول رسومية.
